# 일반 모드와 USB 전용 동글 모드를 별도 펌웨어로 제공

> 이후 결정: 기본 키맵의 Soft Off 바인딩 두 곳을 제거한다. 아래 Soft Off에 관한 내용은 당시 설계 결정의 기록이다.

일반 모드의 왼쪽 Central 구성을 보존하면서, 동글 모드에서는 좌우 키보드를 모두 BLE Peripheral로 구성하고 OLED 동글을 Central로 사용한다. 사용자는 2026-11-07에 두 모드의 전환을 별도 UF2 재플래시와 필요한 BLE 연결 정보 초기화로 수행하는 방식을 선택했다. 실행 중 Central/Peripheral 역할을 전환하는 기능은 이번 범위에 포함하지 않는다.

동글은 컴퓨터에 USB HID로 입력을 전달하고, DYA Studio 설정에는 별도의 USB 직렬 연결을 사용한다. 키보드와 동글 사이에는 BLE를 사용한다. 동글 모드에서 기존 키맵의 컴퓨터 Bluetooth 프로필 선택·삭제 및 BLE 출력 전환 키는 무동작으로 처리한다. 일반 모드에서는 기존 Bluetooth 기능을 유지한다. 이 선택은 동글 사용 중 출력이 Bluetooth로 전환되는 것을 방지하지만, 동글 자체를 컴퓨터의 Bluetooth 키보드로 사용하는 기능은 제공하지 않는다.

동글 모드의 Soft Off 명령(Q/S/Z 2초 조합 포함)은 좌우 키보드만 종료하고 USB 동글은 계속 켜 둔다. 기존 전역 soft-off 동작은 Central까지 종료하므로 그대로 재사용하지 않는다. 키보드는 기존처럼 리셋 버튼으로 깨우며, 일반 모드의 Soft Off 동작은 유지한다.

절전 중에는 OLED 동글의 화면을 끈다. USB 동글이 계속 동작한다는 것은 화면을 계속 켜 둔다는 뜻이 아니다. Idle에서 키 입력 등으로 활동이 재개되면 화면을 다시 켜고, Soft Off에서는 키보드를 리셋해 복귀한 뒤 입력이 재개되면 화면을 다시 켠다. 동글은 화면이 꺼져 있는 동안에도 입력을 다시 받을 수 있도록 USB·BLE 동작을 유지한다.

구현 범위와 인수·검증 기준은 [스펙 #1](https://github.com/kalstein00/zmk-sofle/issues/1)에 기록한다. 이 문서는 설계 결정이며 구현 완료를 뜻하지 않는다.
