# USB 전용 동글을 보존하고 무선 동글의 출력 대상을 명시적으로 선택

2026-11-20 사용자는 기존 USB 전용 동글 빌드를 유지하고 별도 무선 동글 빌드를 추가하기로 결정했다. 일반 모드와 좌우 키보드의 역할은 유지하며, 좌우 펌웨어는 가능한 한 공유해 동글 변경에 따른 재설치를 최소화한다. 기존 USB 전용 빌드는 복구 경로로 보존한다. 이는 ADR-0001의 USB 전용 제약을 기존 빌드에 유지하면서 무선 동글 모드를 추가하는 결정이며 구현 완료를 뜻하지 않는다.

무선 동글 모드에서 PC 프로필을 선택하면 BLE 출력도 함께 선택한다. USB 출력은 사용자가 명시적으로 선택하며, 충전이나 DYA Studio를 위해 USB를 연결해도 BLE 출력을 유지한다. 선택한 BLE 호스트의 연결이 끊어지면 재연결을 시도하고 USB로 자동 전환하지 않는다. 고정 ZMK의 기본 동작은 프로필 선택과 출력 선택을 분리하고 연결 가능한 출력으로 자동 전환하므로, 이 동작을 그대로 사용하는 대신 입력 대상이 사용자 선택 없이 다른 컴퓨터로 바뀌지 않도록 한다.

## 합의한 사용 정책

2026-11-20 사용자가 Q5~Q12의 추천안을 승인하고 Phase 1 구현을 요청했다.

- 집·회사 PC는 Windows 11이며, 회사에서 Bluetooth 키보드 등록이 허용된다. 최종 PC 전환 수단은 OLED 메뉴이고, Phase 1에서는 키 명령으로 먼저 검증한다.
- PC 프로필은 0~3의 네 개를 제공하고, 프로필 전환 시 이전 PC 연결을 끊고 선택한 PC 한 대만 연결한다. 좌우 키보드의 BLE 연결과 본딩은 유지한다.
- 마지막 PC 프로필과 USB/BLE 출력 선택을 재부팅 후 복원한다. 저장된 선택이 없으면 USB 출력으로 시작한다. 빈 프로필은 사용자가 선택했을 때 페어링을 시작한다.
- Phase 1은 현재의 PIN 없는 Just Works 인증을 유지한다. 빈 프로필의 페어링 대기는 120초로 제한하며, 다시 선택하면 재시도한다. 다른 프로필 선택은 이전 페어링을 취소한다. 등록된 PC의 일시적인 연결 끊김에는 재연결을 계속 시도한다.
- PC 프로필 삭제는 PC 본딩만 지운다. 전체 PC 프로필 초기화도 키보드 본딩이나 DYA 키맵을 지우지 않는다. 설정 초기화 UF2는 이 명령들의 구현으로 사용하지 않는다.
- PC 전환 전에 이전 출력 대상에 키·소비자키·마우스 버튼 해제를 보내고, 누른 키가 모두 해제된 뒤 새 입력을 받는다. 전환 중 입력을 새 PC에 재생하지 않는다. 이미 시작된 비동기 동작과 HID 대기 입력도 새 PC로 넘어가지 않도록 처리한다.
- 메뉴 진입 전용 동작은 레이어 2의 위치 59에 둔다. 현재 DYA 키맵에서는 오른쪽 엄지의 `]`이며, 레이어 2 키인 위치 60 바로 왼쪽이다. 자주 쓰는 `.` 위치는 기본 레이어의 입력을 따른다. 기존 DYA 저장 키맵은 보존하고, 사용자가 원하는 키에 메뉴 진입 동작을 지정할 수 있게 한다. 메뉴의 방향키·Enter·Esc는 기본 키맵의 물리 위치를 사용한다. 메뉴 중에는 엔코더·마우스·매크로를 포함한 PC 입력을 차단한다.
- 삭제 확인의 기본 선택은 취소다. 사용자가 삭제를 선택하고 Enter로 확정한다. Esc는 뒤로 가기·취소이며, 메뉴는 30초 무입력 시 종료한다. 메뉴 종료는 진행 중인 120초 페어링 대기를 취소하지 않는다.
- 동글에는 이미 배터리가 장착되어 있으므로 기존 배터리를 사용한다. 새 PCB·배터리 장착 작업을 전제로 하지 않는다.

## 구현 및 검증 순서

1. Phase 1: 별도 무선 동글 빌드, BLE 호스트와 좌우 동시 연결, 키 명령을 통한 프로필 선택·삭제·출력 전환, 안전한 PC 전환과 페어링 복구를 구현한다.
2. Phase 2: 활성 출력·프로필, 페어링·연결·실패 상태를 OLED에 표시한다. 기존 좌우 배터리·레이어·애니메이션과 화면 절전을 유지한다.
3. Phase 3: 합의한 키보드 조작형 OLED 메뉴와 확인 절차를 구현한다.
4. Phase 4: 기존 배터리로 USB 없는 구동, 소비 전류·사용 시간, 절전·재연결·장시간 동작을 검증한다.

각 단계에서 기존 입력과 DYA USB 연결의 회귀를 확인한다. 빌드·호스트 자동 시험과 실기 검증은 구분한다. Phase 1은 Windows 11 집·회사 PC의 실제 페어링·전환과 좌우 동시 연결이 확인되어야 인수 완료다. USB 대비 BLE 지연 및 기존 배터리 소비 전류·사용 시간을 먼저 측정하고, 수치 목표를 확정하기 전에는 관련 NFR을 완료로 처리하지 않는다.
